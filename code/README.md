# AI 时代的编程学习模式（基础：Python）

> **草案，方向未定，仍在讨论中，下面的阶段和优先级只是候选，不是定论。**
> 2026-11-02 初稿。核心观点：AI 能写大量代码之后，**写**的要求在降低，**读懂、说清需求、验收、判断**的要求在升高。

## 一、核心模式：四级 AI 使用法

| 级别 | AI 的角色 | 什么时候用 |
|---|---|---|
| L0 不用 AI | 无 | 基础语法练习、闭卷复现 |
| L1 AI 当老师 | 只解释、只给提示，不给答案 | 卡住超过 10 分钟 |
| L2 AI 当搭档 | 它写，你逐行读，必须能讲出每行在干什么 | 做项目 |
| L3 AI 当工人 | Claude Code 写整个项目，你写需求、做验收 | 做 App、网站 |

**规则**：能升到下一级的前提，是上一级你能闭卷做出来。

### 每次 30 分钟的循环
1. **预测（5 分钟）**：让 AI 给一段代码，先不运行，猜它输出什么。
2. **改写（15 分钟）**：改一个功能，或者关掉 AI 自己从头写一遍。
3. **讲解（10 分钟）**：用费曼法讲给 AI 听，让它挑错、出 2 道小题。

每天结束 `git commit` 一次，GitHub 就是作品集。

## 二、AI 时代真正要练的 6 种能力

| 能力 | 具体是什么 | 怎么练 |
|---|---|---|
| 读代码 | 看懂 AI 写的几百行，知道每一块在做什么 | 每次让 AI 写完，先讲一遍再运行 |
| 说清需求 | 把模糊的想法写成精确的规格：输入、输出、边界情况 | 写需求文档，再让 AI 实现，看它理解对不对 |
| 验收和测试 | 设计测试来证明代码对，而不是"跑起来没报错" | 学 pytest，先写测试再让 AI 写代码 |
| 调试 | 出错时能定位是哪一层的问题 | 学会看报错信息、打印中间变量、二分排查 |
| 系统设计 | 一个产品由哪几块组成，数据怎么流动 | 画架构图，学数据库、API、云部署的基本概念 |
| 领域知识 | 你要解决的问题本身，比如物理、数据、业务 | AI 替代不了，这是护城河 |

### 自测三问
1. AI 给我一段 100 行的代码，我能不能 10 分钟内讲清楚它在干什么？
2. 我能不能在不看答案的情况下，说出它可能在哪里出错？
3. 我能不能写 3 个测试，证明它是对的？

三个都能做到，就达到了"能指挥 AI"的水平。

## 三、学习阶段（候选方案，可调整）

**阶段 1：2026 年 11–12 月，Python 基础**
- 内容：变量、list/dict、函数、循环、读写 CSV、git。
- 结业项目：分析自己的业务数据（如销售记录 CSV），按品类算利润和月度趋势。

**阶段 2：2027 年 1–3 月，科学计算**
- 内容：NumPy、Matplotlib、pandas。
- 结业项目：一个英文 README 的仓库 `physics-sim`，含简谐振子的薛定谔方程数值解、Ising 模型的蒙特卡洛模拟。第一个例子见 [`01_harmonic_oscillator.py`](01_harmonic_oscillator.py)。

**阶段 3：2027 年 4–7 月，做一个真产品**
- 用 Claude Code 做一个自己想用的网页，部署到云上，有真实用户。

### 时间安排
- **周一到周四**：只做"物理数值计算"类的编程，同时算物理学习。
- **周五到周日**：做项目，每次 1–2 小时。

## 四、Python 学完往哪延伸

| 方向 | 下一步学什么 | 对应 |
|---|---|---|
| 数据科学 / AI | pandas → scikit-learn → PyTorch，加 SQL | 数据科学家岗位 |
| 科学计算 / 研究 | SciPy、JAX，量子计算框架 Qiskit | 物理修士、研究职 |
| 云 / 基础设施 | Linux、Docker、AWS 认证 | 云方案架构师岗位 |
| Web 产品 | FastAPI、HTML/JavaScript/TypeScript、数据库 | 自己做产品、业务自动化 |
| 高性能 | C++ 或 Rust | 需要时再学 |

**优先级**：暂未确定，待讨论后再定（之前的初步想法是数据科学和科学计算为主，云为辅）。

### 学习层次
- **第一层（必学）**：Python 基础够用就行，能读懂、能改。
- **第二层（重点）**：测试、调试、git、读报错，这是"验收 AI"的核心。
- **第三层（拉开差距）**：系统设计、数据库、云基础，能看懂一个完整产品。
- **第四层（优势）**：数值计算、数据分析，用在物理上。

## 五、第一个例子

[`01_harmonic_oscillator.py`](01_harmonic_oscillator.py)：用有限差分法数值求解一维简谐振子的能级（$\hbar = m = \omega = 1$，理论值 $E_n = n + \tfrac{1}{2}$）。

运行：

```bash
pip install numpy
python3 01_harmonic_oscillator.py
```

练习：把势能换成无限深方势阱或 $V = x^4$，先预测能级会怎么变，再运行验证。
