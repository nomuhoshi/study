# AI 时代学编程：目标是数据 / AI 类实习

> 2026-11-09 定稿（经 grill-me 对齐）。取代 2026-11-02 的草案。

## 目标

- **大三夏天（2027 年 7–9 月）拿到数据科学家 / AI 类实习。**
- 投递时间：2027 年 4–6 月。现在是大二（2026 年 11 月），约 6 个月。
- 投入：每天 30–60 分钟，合计约 120–180 小时。

## 为什么这样排

验收这件事的是招聘方，所以顺序对准选拔流程：

**ES → SPI / 编程测试 → 面试深挖项目和思考过程**

例：Recruit 数据科学家夏季实习的编程测试是 5 题（统计 1、pandas 操作 3、建模 1），面试重点问编程能力和做事的思考过程。

所以：

- **不冗余**：pandas 和统计要练到不靠 AI 也能手写，因为考试要自己写。
- **冗余**：终端和 git 命令、背框架细节、LeetCode 难题。

## 学习顺序

| 阶段 | 时间 | 学什么 | 产出 |
|---|---|---|---|
| 1 | 2026 年 11–12 月 | Python + pandas，**手写**，AI 只当老师（L1） | 用自己的 Mercari 数据做汇总分析 |
| 2 | 2027 年 1–2 月 | 统计（描述统计、假设检验、回归、A/B 测试 / 効果測定）+ SQL 基础 | 每个概念用 Mercari 数据做一遍 |
| 3 | 2027 年 3–4 月 | scikit-learn 回归和分类，评估方法，过拟合 | 主打作品：Mercari 的"多少钱、多久能卖掉"预测，并用结果改定价，写成 GitHub README |
| 4 | 2027 年 4–6 月 | ES、SPI、限时模拟编程测试、练面试里讲作品 | 至少投 5 家 |

## 用 AI 的规矩

- 考试要考的（pandas、统计）：**自己写**，AI 只解释、只给提示。
- 作品：AI 可以帮你搭架子，但**每一行都要能讲清楚**，面试会深挖。
- 每次学习：先预测输出，再运行，最后讲给 AI 听，让它挑错。

## 过关标准与调整线

- **过关**：2027 年 4 月前，限时内不用 AI 做完一套类似 Recruit 的 5 道题；GitHub 上有 1 个带决策故事的作品；至少投 5 家。
- **调整线**：2026 年 12 月底，如果还写不出不看资料的 `groupby` 汇总，就放慢节奏，砍掉建模的深度，优先保证编程测试能过。

## 不做的

终端和 git 命令、深度学习、云、LeetCode 难题、物理模拟作品（物理留作 ES 里的差异点）。
