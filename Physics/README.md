## 知识点笔记

### 2026-10-23 連続時間力学系
- 状态向量 $\mathbf{x} = (x_1, \dots, x_n)$：描述系统"此刻全部状态"的一组数（如位置+速度）。
- 力学系 = 规则 $\dot{\mathbf{x}} = \mathbf{f}(t,\mathbf{x})$：给出当前状态，就知道状态怎么变。
- 线性系：$\mathbf{f} = A\mathbf{x}$，$A$ 是 $n\times n$ 常数矩阵；每个 $\dot{x}_i$ 只是 $x_j$ 的一次式，无 $x^2$、$\sin x$、$x_1x_2$。
- 关键技巧：二阶方程 $m\ddot{x} = -kx$ → 令 $x_1 = x,\ x_2 = \dot{x}$ → $\dot{x}_1 = x_2,\ \dot{x}_2 = -(k/m)x_1$ → $A = \begin{pmatrix}0 & 1\\ -k/m & 0\end{pmatrix}$。
- 非线性例：单摆 $\dot{x}_2 = -(g/l)\sin x_1$（含 $\sin$）。
