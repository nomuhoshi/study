## app 解说里的词汇注释

- Would you be interested in doing ~?：「~することに興味はありますか」，用来委婉地打听对方意愿。常见的回应有 I'd have to think it over（需要好好考虑一下）。
- room 作不可数名词 = 空间、余地、场所；作可数名词 = 房间。room 的发音有时听起来像「ウーム」。
- training（研修）和 train（电车）、project 和 projector、recommendation 和 suggestion 是听力里常见的混淆/同义对。
- anonymously = 匿名で（anonymous 的副词）
- publish = ~を出版する、发行（和 newspaper 相关）
- relocate = 移転する（搬迁、调动）
- exhibit：on exhibit = 展示されている（展览中）
- as soon as I can = できるだけ早く
