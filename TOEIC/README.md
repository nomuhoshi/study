# TOEIC / 托业单词与短语学习

目标分数 900+。这个文件夹只放托业的材料，和 `../TOEFL/` 互不相关。

## 用途

做完托业题之后，把文章原文（文字版，不存图片）存在这里，再逐句学习里面的单词和短语。目的是学词汇，不是解题，所以这里不记录选项、答案和对错。

## 目录

- `passages/` —— 每篇文章一个文件：原文、app 解说里的词汇注释，学过的篇目还有逐句的单词/短语讲解。
